## 🔎 About the Project

This project is a **browser-based network traffic analyzer simulator** designed to demonstrate how network monitoring tools work. It provides real-time packet simulation, protocol filtering, and visualization features inspired by professional tools.

---

## ✨ Features

* 📡 Real-time packet simulation
* 📊 Protocol distribution charts
* 🔍 Packet inspection interface
* 🎯 Traffic filtering (TCP, UDP, HTTP, etc.)
* 🌍 DNS lookup tool
* 🌐 HTTP request analyzer
* 🧮 Subnet calculator
* 🛠 Packet builder utility
* 📁 Export data (CSV / JSON / reports)

---

## ⚠️ Important Disclaimer (READ THIS)

> ❗ This is **NOT a real network packet analyzer**.

Due to **browser security and privacy restrictions**, this application **cannot capture or monitor real network traffic**.

### 🚫 Limitations:

* No real packet sniffing
* No system/network-level access
* No actual TCP/UDP stream capture

### ✅ Purpose:

This tool is built **strictly for educational and demonstration purposes** to help users understand:

* How network traffic analyzers work
* Protocol behavior and packet flow
* Basic networking concepts

---

## 🧠 How It Works

The application uses a **simulation engine** to generate mock network packets and visualize them in real time. It mimics the behavior of tools like Wireshark but operates entirely within the browser environment.
